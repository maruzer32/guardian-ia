# GUARDIÁN IA: IoT & Multimodal AI Copilot for Visual Disability (MVP & Investment Blueprint)

## 💡 Elevator Pitch
Guardián IA es el primer asistente de vida integral de bajo costo, impulsado por Inteligencia Artificial multimodal, diseñado para devolver la autonomía, seguridad financiera y libertad de movimiento a las más de 2.200 millones de personas con discapacidad visual en el mundo.

## 🛠️ Simulación de Hardware Virtual Integrada (MVP a Costo Cero)
Hemos diseñado una arquitectura híbrida eficiente que equilibra potencia y bajo costo, evitando hardware innecesariamente caro y delegando el procesamiento pesado en la nube. 

Podés auditar, testear y ejecutar nuestro circuito de hardware de forma 100% interactiva en tiempo real a través del siguiente laboratorio virtual:

👉 **[Ejecutar Prototipo Virtual Interactivo en Wokwi](https://wokwi.com/projects/474299948738183169)

### ⚙️ Instrucciones para la Validación Técnica en Vivo:
1. Hacé clic en el botón verde de **Play** (Start Simulation).
2. La consola de comandos desplegará el inicio del sistema y la secuencia: `START NET...` -> `Connecting...` -> `ONLINE!`.
3. Una vez asignada la IP virtual, hacé clic directo sobre el sensor ultrasónico azul (**HC-SR04**).
4. Desplazá el control de distancia a **menos de 50 cm** y observarás en la consola las alertas perimetrales del software en tiempo real (`ALERT! Distance...`).

## ⚙️ Arquitectura Tecnológica Scalable
- **Capa de Hardware (Edge):** Firmware optimizado en **MicroPython** corriendo sobre un microcontrolador **ESP32**, integrado con sensores ultrasónicos de proximidad y lógica háptica periférica.
- **Capa de Inteligencia Artificial (Core):** Pipeline de conectividad de red preparado para el envío de payloads multimedia hacia modelos masivos multimodales rápidos de baja latencia (**Google Gemini 1.5 Flash / Azure OpenAI**).

## 📈 Modelo de Impacto e Inversión (B2B2G)
- **Validación en Territorio:** Proyecto en fase de articulación estratégica con la *Asociación Tiflológica Luis Braille* (Mendoza, Argentina) para pruebas de usabilidad y validación de campo.
- **Estrategia Comercial:** Comercialización directa mediante subsidios estatales, Ministerios de Salud y Obras Sociales (Alineado con las directrices de Microsoft AI for Accessibility).
